## Problem

The `\paragraph{Hypothesis testing and the Test Statistic.}` block in §3.1.2
(currently lines 69–96) carries four distinct statistical tasks under one
header — significance testing (TS/Wilks), interval estimation (only hinted at
in a commented-out line), goodness-of-fit (KS), and non-nested model selection
(AIC). A single catch-all transition ("when these assumptions do not hold")
conflates three different failure modes. The bootstrap is missing entirely
(placeholder `% bootstrap` at line 84), and confidence intervals are never
introduced even though §3.1.3 later contrasts credible intervals against them.

Bryan's notes: **116** — add frequentist uncertainty estimation (bootstrap,
confidence intervals); **120** — correct §3.1.4, bootstrap is always available
in the frequentist case; **121** — remove the MCMC poor-mixing point in §3.1.4.

## Structural decisions (bullet points only — prose is the drafting step's job)

### 1. Split the block into four task-scoped `\paragraph` lead-ins

- `\paragraph{Hypothesis testing and confidence intervals.}`
  - TS definition (keep eq. `eq:ts`), Wilks' theorem, TS → significance
    conversion (existing content, tightened).
  - Interval construction by thresholding the profile-likelihood TS — restore
    the commented-out one-sided 95% CL / TS = 3.84 example (line 79).
  - Rationale for merged title (user decision): the Wilks-based confidence
    interval is the inverted hypothesis test — same TS, same χ² quantile.
- `\paragraph{Bootstrap confidence intervals.}` **(new)**
  - When Wilks' conditions fail: parameter on a physical boundary,
    small-sample regimes where asymptotics have not set in, non-nested
    hypotheses.
  - Bootstrap principle: refit on resampled datasets (nonparametric) or on
    datasets drawn from the fitted model (parametric); take containment
    intervals of the re-fitted estimates.
  - Cite Efron 1979 (see §4 below).
  - Close with in-place application pointer: the Chapter 5 ⟨σv⟩ uncertainty
    band is a parametric bootstrap (100 HMC-sampled datasets from the
    best-fit mixture model, 95% containment —
    `chapter_05/.../mixture_model_and_limits.tex:322–325`).
  - Title parallels "Credible intervals versus confidence intervals." in
    §3.1.3.
- `\paragraph{Goodness of fit.}`
  - KS-test content essentially as is; own transition: absolute compatibility
    of data with a single model, no specific alternative.
- `\paragraph{Non-nested model comparison.}`
  - AIC content as is (keep the `\blue{}` sentence); the non-nested motivation
    moves here from the dissolved catch-all transition.
- The bridge sentences at lines 81–82 ("relies on nested hypotheses … other
  frequentist tools are available") are dissolved: each failure mode lives
  with its remedy.
