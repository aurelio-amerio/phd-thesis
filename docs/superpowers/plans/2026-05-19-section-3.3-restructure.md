\section{Machine Learning in Astrophysics}
\label{sec:3.3}

The simulation-based inference framework of Section~\ref{sec:3.2} already uses machine learning to approximate intractable posteriors, but machine learning enters this thesis through two distinct paradigms. \emph{Image-domain analyses} feed pixel arrays directly into a neural network: the convolutional architectures of computer vision are a natural choice because their inductive biases---locality, weight sharing, translation equivariance---align with how astrophysical signals appear on detectors. Chapter~\ref{ch:6} adopts this paradigm to reconstruct the source-count distribution from gamma-ray sky maps. \emph{Summary-statistic analyses}, in contrast, first reduce each object to a low-dimensional feature vector and apply machine learning to those features; Chapter~\ref{ch:5} adopts this paradigm to search for a dark matter subhalo population among unassociated Fermi-LAT sources. Both paradigms are widely used in astrophysics; the choice depends on data type and scientific question.

This section provides the minimum machine-learning vocabulary needed to read those two chapters: the canonical learning tasks (Section~\ref{sec:3.3.1}); neural networks, their training, and uncertainty estimation (Section~\ref{sec:3.3.2}); convolutional architectures and their spherical extensions for sky-map data (Section~\ref{sec:3.3.3}); and classical non-parametric density estimation for population-level inference on feature vectors (Section~\ref{sec:3.3.4}). The treatment is a primer rather than a survey; references are given throughout for readers who want more.
