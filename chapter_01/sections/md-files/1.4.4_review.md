## Important Issues (🟡)

### Issue 1: Ambiguity in D-factor robustness claim
- **Location**: Section 1.4.4, paragraph on D-factor (line ~110)
- **Quote**: "it is far less sensitive to the choice of density profile and to substructure boost factors — neither of which affect the decay signal"
- **Problem**: The em-dash clause "neither of which affect the decay signal" could be read as saying profile choice doesn't affect D at all, which is slightly overstated. Profile choice *does* affect D — just much less dramatically than J. The "neither" applies accurately to boost factors but is imprecise for profile sensitivity.
- **Suggested fix**: Revise to: "...and to substructure boost factors, which are entirely absent for decay \cite{Cirelli:2024ssz}." The profile sensitivity point is already made by "far less sensitive", so the em-dash clause can focus only on boost factors.

### Issue 2: Missing Bonnivard reference for dSph J-factor uncertainties
- **Location**: Section 1.4.4, paragraph on integrated J-factors (line ~118)
- **Quote**: "depending on the system's mass, distance, and the quality of the kinematic data used to reconstruct its density profile"
- **Problem**: The `references.md` lists `Bonnivard:2015xpq` as a key reference for J-factor determination in dSphs. This reference should be cited here alongside Hooper and Cirelli, as it is the standard methodological reference for dSph J-factor uncertainties.
- **Suggested fix**: Add `\cite{Bonnivard:2015xpq}` to the citation list.

### Issue 5: $r_\odot$ value consistency
- **Location**: Section 1.4.4 uses $r_\odot \simeq 8.33$ kpc (line 100)
- **Problem**: Previous draft used 8.12 kpc. The 8.33 kpc value matches Cirelli's reference but differs from the GRAVITY Collaboration measurement ($8.178 \pm 0.013$ kpc). The value 8.33 kpc from Gillessen et al. (2009) is older. This is not an error but a consistency choice — the same value should be used throughout the thesis.
- **Suggested fix**: Consider using a consistent value. The Cirelli review uses 8.33 kpc; if the thesis follows Cirelli as primary reference, 8.33 kpc is acceptable. Alternatively, adopt the GRAVITY value.
