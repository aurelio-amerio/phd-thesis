\section{Machine Learning in Astrophysics}
\label{sec:3.3}

The simulation-based inference framework of Section~\ref{sec:3.2} already uses machine learning to approximate intractable posteriors, but machine learning enters this thesis through two distinct paradigms.
\emph{Image-domain analyses} feed pixel arrays directly into a neural network: convolutional architectures are well suited to this setting because their inductive biases---locality, weight sharing, translation equivariance---align with how astrophysical signals appear on detectors.
Chapter~\ref{ch:6} adopts this paradigm to reconstruct the source-count distribution from gamma-ray sky maps.
\emph{Summary-statistic analyses}, in contrast, first reduce each object to a low-dimensional feature vector and apply machine learning to those features; Chapter~\ref{ch:5} adopts this paradigm to search for a dark matter subhalo population among unassociated Fermi-LAT sources.
Both paradigms are widely used in astrophysics; the choice depends on data type and scientific question.

This section provides the minimum machine-learning vocabulary needed to read those two chapters: the canonical learning tasks (Section~\ref{sec:3.3.1}); neural networks, their training, and uncertainty estimation (Section~\ref{sec:3.3.2}); convolutional architectures and their spherical extensions for sky-map data (Section~\ref{sec:3.3.3}); and classical non-parametric density estimation for population-level inference on feature vectors (Section~\ref{sec:3.3.4}).
The treatment is a primer rather than a survey; references are given throughout for readers who want more.

\subsection{Learning Tasks}
\label{sec:3.3.1}

Machine learning provides tools for extracting information from data when explicit physical models are either unavailable or computationally intractable~\cite{bishop,Hastie:2009}.
The problems addressed in this thesis fall into three canonical learning tasks.

The first is \textit{classification}: assigning a discrete label to an input based on its observed features.
In the gamma-ray context, this amounts to determining the astrophysical nature of a detected source.
Roughly one-third of the sources in Fermi-LAT catalogs lack firm multi-wavelength associations~\cite{Bhat:2022}, and supervised classification algorithms---trained on populations of identified AGNs and pulsars---are used to predict the class membership of these unassociated objects.
The input features are quantities derived from the gamma-ray signal itself: spectral curvature significance, variability index, hardness ratios, and energy flux~\cite{Bhat:2022}.
In Chapter~\ref{ch:5}, this paradigm is extended beyond standard source classes through a generative mixture model that accommodates an entirely new population---dark matter subhalos---among the unassociated sources.

The second task is \textit{regression}: predicting a continuous quantity from observational data.
In Chapter~\ref{ch:6}, a convolutional neural network estimates the source-count distribution $dN/dS$ directly from gamma-ray sky maps.
By adopting a heteroscedastic loss function (described in Section~\ref{sec:3.3.2}), the network simultaneously performs regression on both the $dN/dS$ values and their associated uncertainties, predicting the variance of each output alongside its mean~\cite{heteroscedastic-error}.

The third task is \textit{density estimation}: approximating the probability distribution from which observed source features are drawn.
While classification asks ``what class is this source?'', density estimation asks the complementary question ``what does the overall population look like?''
This shift from individual classification to population-level inference underpins the generative mixture model developed in Chapter~\ref{ch:5}, where Kernel Density Estimation---used to model the feature distributions of associated sources---is combined with mixture model fitting to infer the energy spectrum composition of the unassociated gamma-ray sources.
Section~\ref{sec:3.3.4} returns to this task with classical non-parametric methods, complementing the neural surrogate approaches introduced in Section~\ref{sec:3.2}.

\subsection{Neural Networks and Deep Learning}
\label{sec:3.3.2}

A neural network is a parametric function $f_{\boldsymbol{w}}: \mathbb{R}^n \to \mathbb{R}^m$ composed of a sequence of affine transformations, each followed by a non-linear activation function.
In a network with $L$ layers, the output of layer $\ell$ is $\mathbf{h}^{(\ell)} = \sigma(\mathbf{W}^{(\ell)}\mathbf{h}^{(\ell-1)} + \mathbf{b}^{(\ell)})$, where $\mathbf{W}^{(\ell)}$ and $\mathbf{b}^{(\ell)}$ are trainable weight matrices and bias vectors, and $\sigma$ is a non-linear function such as the rectified linear unit $\mathrm{ReLU}(x) = \max(0, x)$.
Other activations have been used historically---sigmoid and hyperbolic tangent were standard in earlier architectures---while GELU has become widespread in modern transformer-based models.
Given a sufficiently large number of parameters, neural networks can approximate any continuous function to arbitrary accuracy~\cite{bishop,Goodfellow:2016dlbook}.

Training consists of adjusting the weights $\boldsymbol{w}$ to minimize a cost function $\mathcal{J}(\boldsymbol{w})$ using gradient-based optimisation.
Backpropagation provides the necessary gradients by applying the chain rule recursively through the network layers, yielding the partial derivative of $\mathcal{J}$ with respect to every weight in a single backward pass.
In practice, gradients are estimated from mini-batches rather than the full dataset, giving rise to stochastic gradient descent (SGD) and its modern adaptive variants such as Adam and AdamW~\cite{Loshchilov:2017bsp}, which maintain per-parameter learning rates and momentum estimates.
The empirical success of deep learning over the past decade rests on algorithmic advances together with network depth, large datasets, and GPU-accelerated compute~\cite{LeCun:2015pmr}.

The choice of cost function determines what the network learns.
For a standard regression problem, the mean squared error $\mathcal{J} = \sum_i (y_i^\mathrm{true} - y_i^\mathrm{pred})^2$ penalises deviations between predictions and targets uniformly; for classification, the cross-entropy loss measures the divergence between predicted class probabilities and one-hot labels.
Both can be understood as special cases of the negative log-likelihood under an appropriate probabilistic model~\cite{bishop,Murphy:2022pml}.
When the noise level varies across the output space, the variance can itself be parameterised as a network output, yielding the heteroscedastic Gaussian negative log-likelihood~\cite{heteroscedastic-error}; the formalism is presented in Section~\ref{sec:bayesian-error}, where Chapter~\ref{ch:6} puts it to use.

Beyond a point estimate, predictions carry two distinct sources of error: \textit{aleatoric} uncertainty, intrinsic to the data (irreducible noise that more training data cannot remove), and \textit{epistemic} uncertainty, reflecting the model's ignorance about which parameter values best describe the data (reducible in the limit of infinite data and capacity).
Bayesian neural networks aim to recover both jointly by treating the network weights as random variables rather than fixed parameters, in the same spirit as the simulation-based inference framework of Section~\ref{sec:3.2}.
Chapter~\ref{ch:6} presents one practical realisation of this idea, in which MC dropout and a heteroscedastic Gaussian likelihood are combined to produce per-output mean and variance estimates; the technical formalism is detailed there (Section~\ref{sec:bayesian-error}).
Gal and Ghahramani~\cite{mcdropout} showed that a neural network with dropout applied before every weight layer is mathematically equivalent to approximate variational inference in a deep Gaussian process; at test time, $T$ stochastic forward passes with dropout active yield a sample mean as the predictive estimate and a sample variance as the epistemic uncertainty.

Overparameterised models can memorise the training set; regularisation keeps them honest.
In practice, several complementary techniques are typically used in combination: weight decay (an $L_2$ penalty on the weights), dropout---which randomly zeros a fraction of activations during training---batch and layer normalisation~\cite{batchnorm}, data augmentation, and early stopping.
Dropout doubles as an uncertainty quantifier when left active at test time, as described above, and its self-tuning variant \textit{concrete dropout}~\cite{concrete-dropout} replaces the discrete Bernoulli mask with a continuous relaxation that makes the drop probability differentiable, so that the optimal rate for each layer is learned jointly with the network weights during training.
Chapter~\ref{ch:6} adopts concrete dropout as its regularisation and uncertainty calibration strategy; the specific recipe is detailed there.

\subsection{Convolutional Neural Networks}
\label{sec:3.3.3}

For image-domain analyses, the input is a pixel grid---or, in astrophysics, a HEALPix sky map---and convolutional neural networks (CNNs) exploit this spatial structure directly.
CNNs have been applied to astrophysical problems such as galaxy morphology classification~\cite{Dieleman:2015wdg}, strong gravitational lens identification~\cite{Hezaveh:2017sht}, and electromagnetic transient detection.
In this thesis, Chapter~\ref{ch:6} adopts a CNN to reconstruct the source-count distribution from gamma-ray sky maps.

A convolutional layer applies a set of learnable filters (kernels) to local patches of the input, producing feature maps that respond to spatial patterns at specific scales.
For a two-dimensional input, the discrete convolution of a filter $g$ with an input $f$ is
\begin{equation}
	(f * g)[i,j] = \sum_{m}\sum_{n} f[m,n]\, g[i-m, j-n].
	\label{eq:conv2d}
\end{equation}
Because the same filter is applied everywhere across the input, the number of parameters per layer is independent of the input size, and the response to a given pattern is the same regardless of its location---a property known as translation equivariance.

Stacking convolutional layers builds progressively larger receptive fields: shallow layers detect local features such as edges and peaks, while deeper layers combine these into more abstract representations.
Pooling operations (max or average over local windows) downsample the feature maps between successive convolutional stages, providing approximate translation invariance at the cost of spatial resolution~\cite{Goodfellow:2016dlbook,LeCun:2015pmr}.
This hierarchy of local-to-global features allows CNNs to capture information distributed across spatial scales.

Modern CNNs build on a few architectural ideas: VGG-style stacks of small convolutions~\cite{Simonyan:2014cmh} and the residual connections introduced by ResNet~\cite{he2015deep}, which enabled training of networks hundreds of layers deep.
Contemporary computer-vision architectures often combine convolutional building blocks with attention mechanisms borrowed from transformers, as in vision transformers~\cite{Dosovitskiy:2020qjv} and hybrid models.

A specific challenge arises when the data live on the sphere rather than on a flat grid.
Sky maps live on $S^2$, not $\mathbb{R}^2$: standard CNNs assume Euclidean translation symmetry, whereas the sphere has rotational symmetry instead, and any flat parametrisation introduces distortion that breaks weight sharing.
Three broad strategies have been developed to extend convolutional architectures to spherical data.

The first strategy performs convolutions in the spherical harmonic domain.
Because the spherical harmonics are the natural eigenbasis of the Laplace--Beltrami operator on $S^2$, a spectral convolution can be defined in exact analogy with the classical convolution theorem on the real line.
\texttt{DeepSphere}~\cite{DBLP:journals/corr/abs-2012-15000} implements this idea using a graph-based approximation, representing the sphere as a graph whose nodes are HEALPix pixels and whose edges encode pixel adjacencies; spectral graph convolutions then replace the standard spatial filters.
This approach preserves the global topology of the sphere and handles irregular pixelisations.

The second strategy applies convolutions to local projections of the sphere.
Rather than operating on the curved manifold directly, these methods project spherical patches onto tangent planes or polyhedral faces, where standard 2D convolutions apply without modification.
Icosahedral projections~\cite{eder2019convolutions} decompose the sphere into 20 equilateral triangular faces that cover it nearly uniformly, limiting the distortion inherent in any flat projection.

The third strategy, and the one most directly relevant to this thesis, operates on the HEALPix pixelisation itself.
\texttt{NNHealpix}~\cite{Krachmalnicoff:2019} exploits the fixed neighbourhood structure of HEALPix pixels by unrolling each pixel and its eight nearest neighbours into a nine-element vector and applying standard 1D convolutions with stride nine.
This preserves the full topology of the sphere at the cost of higher computational overhead and sensitivity to the orientation of pixel neighbourhoods.
The \texttt{map2patch} algorithm developed in Chapter~\ref{ch:6} subdivides the sphere into the 12 equal-area base pixels of the HEALPix scheme and treats each as an independent flat image processed through standard 2D convolutions.
This subdivision preserves the exact area and photon content of every pixel without resampling, at the cost of discarding spatial information at patch boundaries; details of the implementation are deferred to Chapter~\ref{ch:6}.
For statistically isotropic, small-scale signals such as the point-source population studied in Chapter~\ref{ch:6}, \texttt{map2patch} and \texttt{NNHealpix} produce compatible results, while \texttt{map2patch} achieves more than an order of magnitude improvement in execution speed.
More recently, \texttt{HEAL-SWIN}~\cite{carlsson2024healswin} adapted the Swin Vision Transformer to the HEALPix sphere: shifted-window attention operates within local HEALPix patches, and the window boundaries are shifted between successive transformer blocks so that the model captures both local and global spherical structure while retaining the computational efficiency of window-based attention.

\subsection{Density Estimation}
\label{sec:3.3.4}

Having introduced the convolutional architectures used for image-domain inference in Chapter~\ref{ch:6}, we now turn to the tools underlying the summary-statistic approach of Chapter~\ref{ch:5}.
The simulation-based inference framework of Section~\ref{sec:3.2} relies on neural density estimators---normalising flows, score-based diffusion models, and flow matching~\cite{Papamakarios:2021,Song:2021zrs,Lipman:2023hef}---that are well suited to high-dimensional or complex distributions~\cite{Cranmer:2020}.
For low-dimensional, well-defined feature spaces, classical non-parametric methods such as Kernel Density Estimation and mixture models with Expectation-Maximisation are sufficient and often preferable.
Chapter~\ref{ch:5} sits squarely in this regime: the input features are a handful of spectral and variability quantities per source, and the rest of this subsection introduces the classical tools used there.

Given a set of $N$ observed data points $\{\mathbf{x}_1, \ldots, \mathbf{x}_N\}$ drawn from an unknown distribution, the goal is to estimate the probability density function $p(\mathbf{x})$ that generated them.
Unlike classification, which learns a decision boundary in feature space, density estimation reconstructs the full probability distribution and can therefore reveal populations that were absent from the training set.
A non-parametric approach to this problem is provided by Kernel Density Estimation (KDE).
Given $N$ samples, the KDE approximation to the density at a point $\mathbf{x}$ is
\begin{equation}
	\hat{p}(\mathbf{x}) = \frac{1}{N} \sum_{i=1}^{N} K_h(\mathbf{x} - \mathbf{x}_i),
	\label{eq:kde}
\end{equation}
where $K_h$ is a kernel function with bandwidth $h$.
For a Gaussian kernel, $K_h(\mathbf{u}) \propto \exp(-\|\mathbf{u}\|^2 / 2h^2)$, and the bandwidth controls the trade-off between bias and variance: too small a bandwidth overfits the sample, while too large a bandwidth oversmooths the underlying structure.
The optimal bandwidth is determined through cross-validation, selecting the value that maximises the model likelihood on held-out data.
Separate KDE models are computed independently for each source class (Galactic and extragalactic), yielding the class-conditional densities $p_\mathrm{assoc}(\mathbf{x}|k)$ that form the building blocks of the mixture model described below.

When the observed data arise from multiple overlapping populations, the total density can be written as a mixture model,
\begin{equation}
	p(\mathbf{x}) = \sum_{k=1}^{K} \pi_k \, p(\mathbf{x}|k),
	\label{eq:mixture_model}
\end{equation}
where $\pi_k$ are the mixing weights (class prevalences) satisfying $\sum_k \pi_k = 1$, and $p(\mathbf{x}|k)$ is the class-conditional density.
The mixing weights and any free parameters of the component densities are typically determined by the Expectation-Maximisation (EM) algorithm~\cite{Dempster:1977}: an iterative procedure that alternates between computing the posterior class responsibilities $\gamma_{ik} = p(k | \mathbf{x}_i)$ for each data point (the E-step), and updating the model parameters to maximise the expected log-likelihood under those responsibilities (the M-step).
For the mixing weights, the M-step admits a closed-form solution: $\pi_k^\mathrm{new} = N^{-1}\sum_i \gamma_{ik}$, i.e., each weight is updated as the average posterior responsibility over the dataset.

In Chapter~\ref{ch:5}, this framework is extended to search for dark matter subhalos among the unassociated Fermi-LAT sources.
The mixture model combines astrophysical class-conditional densities with a covariate shift correction (Section~\ref{sec:3.4}) and a possible dark matter component, with class prevalences determined via the EM algorithm following the approach of Saerens et al.~\cite{10.1162/089976602753284446_Saerens}.
