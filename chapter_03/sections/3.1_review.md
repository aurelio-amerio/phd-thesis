## Important Issues (🟡)

### Issue 1: Likelihood described as "probability"
- **Location**: 3.1.1, paragraph 2
- **Quote**: "evaluates the probability of observing the data given a specific parameter choice"
- **Problem**: The likelihood is a function of parameters for fixed data; it is not a normalized probability distribution over data.
- **Fix**: Change to "quantifies how well the parameters explain the observed data"

### Issue 2: Cramér-Rao bound uncited
- **Location**: 3.1.2, paragraph 2
- **Problem**: Asymptotic efficiency claim stated without reference.
- **Fix**: Remove the specific Cramér-Rao claim (it's a textbook result not central to the argument) and keep the simpler statement.

### Issue 3: Integrated likelihood weight function under-explained
- **Location**: 3.1.2, paragraph 4
- **Quote**: "$g(\boldsymbol{\eta})$ is a weight function that may encode prior measurement uncertainties"
- **Problem**: Ambiguous — reads as if $g$ is arbitrary. In practice, it comes from auxiliary measurements.
- **Fix**: Clarify that $g(\boldsymbol{\eta})$ typically comes from independent constraints or auxiliary measurements.

### Issue 4: Mattox bib key unverified
- **Location**: 3.1.2
- **Problem**: `references.md` notes `Mattox:1996` as "needs checking". Must verify or flag.
- **Fix**: Keep the citation but note for user to verify bib key.

### Issue 5: Bold markdown headers inconsistent with LaTeX

- **Fix**: Will be handled in LaTeX conversion.
