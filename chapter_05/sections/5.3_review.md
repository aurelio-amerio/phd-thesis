### Issue 1: Repeated J-factor integration radius discussion
- **Location**: §5.3.1 para 4 and §5.3.2 para 1
- **Problem**: The $J_{0.1}$ vs $J_\mathrm{tidal}$ integration radius is discussed in both subsubsections. In §5.3.1, it appears in the angular extent paragraph; in §5.3.2, it returns as "Second" uncertainty axis. There is some redundancy.
- **Suggested fix**: In §5.3.1, keep only the observational fact (most subhalos are point-like, so $J_{0.1}$ is used). In §5.3.2, focus on the uncertainty implications (different integration radii lead to different detection counts). Current text is not contradictory, so this is polish rather than a fix. Leave for user judgment.

### Issue 2: Missing explicit CosmiXs citation in §5.3.1

- **Suggested fix**: Add `\cite{2024JCAP...03..035A}` alongside or after `\cite{Cirelli:2024ssz}` when discussing spectral shape calculations, or note that the specific spectra used in this work are taken from CosmiXs.
