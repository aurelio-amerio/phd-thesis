# drafting procedure
- create a notebooklm notebook
- upload my papers, naming them '001) paper name'
- identify and upload core review papers and books, denote them as '002) review name'
- load all the other references cited in my papers, as they can be useful for the literature review, as well as other useful articles
- define a draft of the outline for the thesis, and iterate on that. It is useful to draft this using notebooklm directly, after defining an initial base structure
- once the general thesis outline, do a reference search chapter by chapter, using the literature_research skill
- for each chapter, create a chapter outline using the thesis outline and the outlining skill
- ...
